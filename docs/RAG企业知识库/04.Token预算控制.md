
- 用 MeterRegistry 做 Token 的全局实时监控
- 用 Redis 保存持久化存储每个用户的 Token 用量
	- Key：rag:token-stats:{UserId}
	- value：用 hash存储，field是token使用类型，value是使用量


# 一、Embeding 生成

>tokenMetrics.recordEmbeddingTokens记录

EmbeddingResponse返回响应可以返回 Token用量

```java
long tokens = response.getMetadata().getUsage().getTotalTokens();
```

Embeding的时候是分批批量的，每次将 tokens 累加，然后用 tokenMetrics 记录



# 二、用户上下文 ContextTokens

>tokenMetrics.recordContextTokens记录

1. Reranker

Reranker调用 reranker模型生成，属于用户上下文

Reranker 的模型响应 RerankResponse可以 getTotalTokens


2. 上下文裁剪
查询管道最后要做 Token限制，对上下文进行裁剪

最后得到用户的输入上下文文本

调用 knuddels.jtokkit 库统计文本 text 的 Token 数

```java
private Encoding tokenizer;

tokenizer.encode(text).size();  
```
